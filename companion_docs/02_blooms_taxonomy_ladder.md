# Bloom's Taxonomy ladder — Socratic question stems for this tutor

Source of the pedagogy design behind the tutor's Socratic prompting (per the
project's Rule 3: pedagogy lives in team documents, not the model). Adapted
for OT/NBCOT exam reasoning from the standard Bloom's Taxonomy cognitive
levels. This is the study team's own material — not textbook content.

Each level below moves the student one step up in cognitive demand. The
Reasoning Coach and Explainer use this ladder to (1) name which level a
student's answer/explanation demonstrates, and (2) ask ONE question at the
next level up to move their thinking forward.

## 1. Knowledge — recall facts, terms, definitions
Stems: "What is...?" "Can you name/list...?" "What does [term] mean?"

## 2. Comprehension — explain the idea in their own words
Stems: "Can you explain why...?" "What is happening in this scenario?"
"How would you restate...?"

## 3. Application — use the knowledge in a new clinical situation
Stems: "How would you use this with a client who...?" "What would you do
if...?" "How does this apply to [scenario]?"

## 4. Analysis — break the scenario into parts, find the cause or motive
Stems: "What is the underlying cause/motive here?" "What evidence supports
that?" "How does [factor] relate to [outcome]?"

## 5. Synthesis — combine ideas into a new plan or approach
Stems: "How would you combine these approaches for this client?" "What would
you change to solve...?" "How would you design a plan that addresses both...?"

## 6. Evaluation — judge, justify, defend a choice against alternatives
Stems: "Why is this the BEST choice compared to the alternatives?" "How would
you defend this decision if challenged?" "What would you cite to support
this over another option?"

## How this maps to NBCOT-style items

Most NBCOT items (and this tutor's default questions) sit at Application or
Analysis — the exam tests clinical judgment, not recall. Occasional
Knowledge/Comprehension items are useful for foundational terminology early
in a chapter; occasional Synthesis/Evaluation items (usually the six-option
"pick the 3 best" scenario format) stretch stronger students. The Reasoning
Coach uses the ladder to diagnose a student's explanation and ask a follow-up
one level above where they currently are — never more than one level at a
time.
