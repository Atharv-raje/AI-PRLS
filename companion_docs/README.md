# Companion documents — what belongs in this folder

This folder is the AI tutor's only knowledge source beyond the base model.
It must contain **only the study team's own original material**:

- chapter maps (what each TherapyEd chapter covers, in your own words)
- NBCOT content-outline crosswalks and domain notes
- ACOTE standards crosswalks
- question blueprints, reasoning rubrics, faculty guidance

It must **never** contain text, tables, figures, or questions copied from the
TherapyEd textbook or any other copyrighted source. The tutor points students
to their own copy of the book; it does not carry the book inside it.

Two example files are included to show the intended format. Replace and extend
them with the team's Parts I–VIII working documents (as markdown files), then
rebuild the index:

    python scripts/build_index.py
